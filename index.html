Selected HPC work.

01

Architecture & technical leadership

I lead HPC modernization for a production codebase maintained by 50+ developers, directing three engineers and coordinating two collaborators. I designed a CPU/GPU portability API spanning memory management, kernel execution, and math libraries, and guide architecture and infrastructure planning for government sponsors.

02

Profiling & optimization

My optimizations include a 1.98× routine speedup through loop fusion and improved memory efficiency, and a 10% faster OpenMP submodule with bitwise numerical agreement. I also contributed numerical vectorization to a team effort that delivered a 20% code-wide speedup.

I built a Caliper/Adiak/PAPI profiling library for MPI+GPU and multi-phase MPMD applications. My roofline analyses, hardware-counter measurements, and memory studies informed performance requirements and acceptance criteria.

Instrumentation across CUDA · oneAPI · GCC

03

Numerical libraries

I proposed, secured funding for, and led an MPI meshfree PDE platform using radial basis functions. Its stencil-weight calculation achieved 50–350× speedup on NVIDIA A100 versus AMD EPYC 7413. A separate stencil-application kernel achieved >200× speedup.

I implement selected BLAS/LAPACK routines for Kokkos Kernels Extension and build Serial/OpenMP test infrastructure on Intel and Arm, including a Grace Hopper CI runner. For LLNL’s BOBA tensor-train library, I implemented batched-SVD execution paths across CPUs, GPUs, and MPI-distributed systems.

Eigen/OpenMP · CUDA/cuSOLVER · MPI
RAJA · Umpire · Slurm CI
